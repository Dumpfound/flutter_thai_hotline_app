# flutter_thai_hotline_app

**สายด่วน THAILAND** - Thai Hotline App

## Screens
- SplashScreenUI
- HomeUI (BottomNavigationBar)
  - TravelUI (การเดินทาง)
  - EmgUI (อุบัติเหตุ-เหตุฉุกเฉิน)
  - BankUI (ธนาคาร)
  - PubUI (สาธารณูปโภค)
- AboutUI

## Packages
- google_fonts (Kanit)
- font_awesome_flutter
- url_launcher
- flutter_launcher_icons

## Run
```bash
flutter pub get
flutter run
```

Tested for iPhone 16 Pro Max size.
